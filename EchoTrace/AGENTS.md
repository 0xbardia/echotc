# EchoTrace invariants

- A case maps provenance. It does not certify the claim.
- Pages, drafts, and model output are untrusted. Quotes must be anchored.
- Production writes belong to the user wallet. No server signer.
- Direct Mode must stay labeled. Do not invent transaction hashes, audit badges, or partner counts.
- Same sender and client request id returns the same case. A changed manifest is rejected.
- Only the owner can advance a case. Reads stay public.
- FINALIZED application state is not, by itself, a consensus receipt.
- Deployment and wallet approval happen in the Studio or app UI, not from a script.
